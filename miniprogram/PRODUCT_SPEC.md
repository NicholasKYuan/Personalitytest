> 版本：v1.0 | 更新：2026-08-12 | 负责人：PM

## 一、产品概述

### 1.1 产品定位

将现有 Web 端「星耀启程人格测评」迁移至微信小程序，通过微信社交生态实现裂变传播与付费转化。

### 1.2 核心价值

- **免费层**：完整答题体验 + 四体系概览结果（雷达图 + 简要描述），给用户即时满足感
- **付费层**：29.9 元解锁 AI 深度分析报告（四体系交叉解读 + 个性化发展建议 + 职业方向推荐）
- **裂变层**：分享好友测试，好友付费后分享者获免费复测/折扣券

### 1.3 与 Web 端的差异

| 维度 | Web 端 | 小程序端 |
|------|--------|----------|
| 登录 | 无登录，匿名 | 微信授权登录（wx.login） |
| 题量 | 120 题 | 120 题（不变） |
| 结果展示 | HTML 卡片 | Canvas 雷达图 + 卡片 |
| 付费 | 无付费墙 | 微信支付 29.9 元 |
| 分享 | 下载 HTML | 微信转发 + 海报分享 |
| 用户数据 | session 文件 | 云端持久化 + 本地缓存 |

#### 页面 2：信息填写 `pages/profile/profile`

**页面目的**：收集用户画像信息，用于智能筛选最适配的 120 题。

**页面结构**：

1. **页面标题**：「关于你」
2. **说明文字**：「请填写以下信息，系统将为你智能匹配最适合的测评题目」
3. **表单字段**：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 昵称 | 文本输入 | 可选 | 用于报告中称呼，最多 20 字 |
| 年龄 | 数字输入 | 必填 | 范围 12-80 |
| 性别 | 选择器 | 可选 | 男/女/其他/不愿透露 |
| 当前身份 | 选择器 | 必填 | 初中生到博士生、在职、自由职业、创业、家长、求职 |
| 测评目的 | 选择器 | 必填 | 职业规划、学习方向、留学规划、自我探索等 |
| 当前状态 | 选择器 | 可选 | 稳定期/过渡期/压力期/迷茫期/成长期 |
| 决策时间窗口 | 选择器 | 可选 | 即刻/1年内/1-3年/3年以上 |
| 出生年月日 | 日期选择 | 可选 | 用于传统易学结合解读 |

4. **底部按钮**：「生成我的专属题目」

**交互流程**：
```
用户填写表单
  -> 前端校验必填项
    -> 不通过：字段下方红字提示
    -> 通过：按钮可点击
  -> 点击「生成我的专属题目」
    -> 按钮显示 loading
    -> 调用 POST /api/session 创建会话
    -> 成功：将 session_id 和 questions 存入本地缓存
      -> 跳转 pages/quiz/quiz
    -> 失败：Toast 提示「网络异常，请重试」
```

**关键文案**：

- **页面标题**：关于你
- **说明文字**：请填写以下信息，系统将为你智能匹配最适合的测评题目。所有信息仅用于生成个性化报告，不会公开。
- **按钮文案**：生成我的专属题目
- **隐私提示**：你的信息将被严格保密，仅用于生成测评报告

#### 页面 3：答题页 `pages/quiz/quiz`

**页面目的**：让用户专注、流畅地完成 120 道题。

**页面结构**：

1. **顶部进度条**
   - 左侧：「第 X / 120 题」
   - 右侧：百分比数字
   - 进度条填充动画

2. **题目卡片**（居中，圆角卡片）
   - 类别标签（如「人际交往」）+ 题型标签（「场景选择」/「程度选择」）
   - 题干文字（大号字体）
   - 提示语：「相信你的第一直觉，没有对错之分」
   - 选项列表（2-4 个选项按钮，纵向排列）
   - 选中状态：高亮 + 边框变色

3. **底部导航**
   - 「上一题」按钮（第一题时禁用）
   - 最后一题答完后显示「提交答案」按钮

**交互流程**：
```
进入答题页
  -> 从本地缓存读取 questions 和 session_id
  -> 渲染第一题
  -> 用户点击选项
    -> 选中样式高亮
    -> 800ms 后自动跳下一题
  -> 用户可点「上一题」回看修改
  -> 最后一题作答后
    -> 显示「提交答案」按钮
  -> 点击「提交答案」
    -> 弹窗确认：「确认提交？提交后将无法修改」
      -> 确认：调用 POST /api/submit
        -> 提交成功：跳转 pages/result-free/result-free
        -> 提交失败：Toast 提示，留在答题页
```

**设计要点**：
- 选项点击后有触感反馈（wx.vibrateShort）
- 自动翻页动画：左滑效果
- 支持手势：左滑下一题，右滑上一题
- 离开页面时自动保存进度到本地缓存（防止意外退出丢失）
- 每完成 40 题弹一次鼓励语

**关键文案**：

- **答题提示**：相信你的第一直觉，没有对错之分
- **进度鼓励**（每 40 题）：
  - 40 题：已完成 1/3，你对自我的探索正在深入
  - 80 题：已完成 2/3，马上就能看到你的专属结果了
- **提交确认**：确认提交全部答案？提交后将无法修改
- **提交按钮**：提交答案，查看结果

## 七、技术注意事项

### 7.1 小程序限制与对策

| 限制 | 影响 | 对策 |
|------|------|------|
| 包大小限制 2MB | 题库数据不能打包 | 题库放后端，API 动态获取 |
| Canvas 性能 | 雷达图渲染 | 使用 Canvas 2D API，限制重绘频率 |
| setData 数据量 | 大量题目数据传输 | 分页加载，仅传当前题目 |
| 网络请求并发限制 10 个 | 同时请求多个接口 | 合并请求，队列管理 |
| 小程序码生成 | 需要后端调用微信 API | 后端生成，返回图片 URL |

### 7.2 数据安全

- 用户 openid 不在前端存储，通过 JWT token 认证
- 支付签名在后端完成，前端只调用 wx.requestPayment
- session_id 关联用户 openid，防止越权访问他人报告
- AI 分析内容在后端缓存，付费用户可反复查看无需重新生成

### 7.3 性能优化

- 题目数据一次性加载，本地缓存，减少网络请求
- AI 分析结果后端缓存，避免重复生成（节省 AI 调用成本）
- 雷达图使用 Canvas 2D API，支持动画但不频繁重绘
- 分享海报 Canvas 离屏渲染，避免卡顿
